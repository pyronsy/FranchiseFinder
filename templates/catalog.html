Franchise Catalog

Browsable list of known multimedia franchises, sourced from Wikipedia's Lists of multimedia franchises. Quick Add creates a stub franchise using LLM-only matching (Wikipedia's list doesn't give us a TMDB company/keyword ID to filter on) — you'll land on the edit page afterward to pick its MDBList list before it's usable. This does not auto-import each franchise's actual movies and shows; use Plex Import's Check feature or a normal scan afterward for that, same as any other LLM-only franchise.
